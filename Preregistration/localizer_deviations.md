| 2026-11-27 | **Stage C1 (§4 behaviour and physiology): analyst definitions and readings,** fixed before any stage-C value was computed. (1) *Run set:* the run-level exclusions are applied first, as Inclusion says ("applied once, in this order"), so phase measures use the 102 usable runs. The registered counts for phase measures (70 runs / 40; tracking 67 runs / 38) were taken from step-1 QC, which did not apply the motion gate; they include sub-108 run 1 (motion fail). The effect of keeping that run is reported. (2) *Tracking PLV:* the participant index is the registered one (Indices 10): the length of the mean of the block resultant vectors over compliant blocks of both runs. The run index is the same thing within a run and is used for run 1 vs run 2 ICC(3,1). Step-1 QC averaged block PLVs instead; that form is reported next to it, to check against ICC .43. *Chance:* the registered 200 circular shifts per block, with the aggregate recomputed in each shift. A participant or run is above chance if the observed index exceeds its shift distribution at one-sided p < .05, with p = (1 + #shifts ≥ observed) / 201. (3) *Pair score:* the step-1 cross-validated rule, unchanged. Breaths are pooled over blocks and runs, and chance is the step-1 shift mean. (4) *Localizer pacer PLV:* the step-1 block PLVs on runs that meet Inclusion 12. Index = mean PLV of the real-pacer blocks (Extero or Match) − mean PLV of the null blocks (Rest, Self, Intero vs a virtual pacer), pooled over blocks of both runs. A participant is above chance if a one-sided Mann–Whitney test of real vs null blocks gives p < .05; index > 0 is also reported. (5) *Change-detection pacer PLV* (Indices 9). The belt comes from the raw `.acq`. The BOLD block is found and graded with the step-1 rule (`grade_block`), from the log's first-trigger wallclock of the attempt whose pacer rows match `Data/events/*_pacertrace.tsv`. A run is usable with `resp_runs.csv` belt grade good or degraded, timing exact or good, and pulses = volumes. Polarity is not required, because a PLV magnitude does not depend on the belt's sign. Runs: the 90 swc7p runs (Inclusion 14). Pacer phase is piecewise linear between pacer-trace rows (π per half-cycle). Paced window: onset + 3 s to the earlier of the last pacer row and the epoch end. Null: free epochs, onset + 3 s to the end, against a virtual pacer at the run's baseline half-cycle (the median pulse-2 period, because pulse 1 is truncated). An epoch needs a window of at least 8 s. Index = mean paced PLV − mean free PLV. Above chance is defined as in (4). (6) *Added sensitivity null (not registered):* each paced epoch's belt is compared with the other paced epochs' pacer traces from the same run, aligned at the first pulse, so window length and rate match. (7) *Breathing-run adherence* = the participant's mean registered `adhere_r` over swc7p runs with belt good or degraded and finite `adhere_r`. *Detection rate* = aware / (aware + unaware + wrong-direction) paced epochs, and *mean confidence* is taken over all paced epochs. Both come from the 90 runs' model events, as in E9. MAIA = `maia_ieat_total`. (8) *C1 in the fROIs:* the cross-run C1 (`LOC_L4_gate_subjects.csv`) in the individual C1-rule fROI of each of the five constraint parcels. In AInsR, where the gate made the LOSO fallback primary, the joint 4 mm C1 in the LOSO fROI is reported as well. *C1 in the a-priori masks:* the joint 6 mm C1 mask mean in the same five parcels. (9) *Statistics:* Spearman ρ with a two-sided permutation p (10,000), Pearson r, a percentile bootstrap 95% CI on ρ (10,000), and the JZS BF10 for r (s = 1, as in E9). BH-FDR is applied across a family of 18 relations: tracking × MAIA, detection, confidence and adherence (4); tracking × C1 in five fROIs and five masks (10); Match adherence × breathing-run adherence (1); adherence × H1 mask means (3). Rows that substitute measures (the pair score for PLV, the change-detection PLV index for `adhere_r`) are labelled sensitivity and lie outside the family. (10) *H1 moderation:* the swc7p H6 group model (nilearn permutation, 10,000, seed 20261126), with demeaned adherence in place of MAIA. It is two-sided in each H1 mask (PIns, COper, SM), Bonferroni ×3, and is reported with the mask-mean regression. Set: H1 (47) ∩ adherence available. Added sensitivity: the change-detection PLV index as the moderator. (11) *Added descriptives:* run 1 vs run 2 ICC(3,1) for Match adherence, Extero entrainment and the change-detection PLV index; and the correlation of the change-detection PLV index with `adhere_r`. | The registration names these measures, but not every computational detail. | No stage-C value seen.
